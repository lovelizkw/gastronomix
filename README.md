# Gastronomix 🍅

Веб-приложение для учёта продуктов и работы с рецептами: «цифровой холодильник»,
каталог из **30 рецептов** с КБЖУ и собственные рецепты с фото, количеством
ингредиентов и пищевой ценностью.

## Возможности

- **Регистрация и вход** (email + пароль, better-auth); данные каждого
  пользователя изолированы.
- **Холодильник** — список ваших продуктов (название, категория, количество).
- **Каталог рецептов** — 30 блюд с фото, временем приготовления и КБЖУ на порцию.
- **Поиск и фильтры** — по названию/ингредиентам, калориям и времени; всё
  выполняется на сервере.
- **Избранное** — отметьте блюдо сердечком и смотрите только избранные рецепты.
- **Страница рецепта** `/recipes/:id` — полная карточка с составом и способом
  приготовления.
- **Профиль** `/profile` — данные аккаунта, изменение имени и статистика.
- **Подбор по продуктам** — рецепты ранжируются по совпадению ингредиентов
  с содержимым холодильника.
- **Свой рецепт** — создание, редактирование и удаление:
  - ингредиенты **с количеством** («курица — 400 г»), до 30 позиций;
  - **фото** блюда: JPEG/PNG/WebP, автоматически сжимается до 1000 px в браузере;
  - число порций и **КБЖУ** (калории, белки, жиры, углеводы);
  - способ приготовления.

## Технологии

- React 19 + TypeScript + Tailwind CSS 4
- TanStack Start (SSR + server functions) и TanStack Router
- better-auth — регистрация, вход, сессии
- PostgreSQL (Neon) или встроенная PGLite для локальной разработки —
  схема задаётся миграциями в `migrations/`
- zod — серверная валидация всех входных данных

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:8080`.

База данных:
- по умолчанию используется локальная **PGLite**: данные хранятся в
  `.data/pglite`, миграции применяются автоматически при старте;
- чтобы подключиться к **Neon/PostgreSQL**, задайте переменную окружения
  `DATABASE_URL` и выполните `npm run db:migrate`.

Проверки качества:

```bash
npm run typecheck   # tsc --noEmit
npm test            # 55 тестов (node:test)
npm run lint        # eslint
npm run build       # production-сборка
```

## Структура репозитория

```
├── migrations/          # SQL-миграции: auth, продукты/рецепты, каталог, фото, избранное
├── src/
│   ├── routes/          # страницы: лендинг, вход, регистрация, «Кухня», рецепт, профиль
│   ├── components/      # UI-компоненты (навигация и др.)
│   └── lib/             # API (server functions), БД, авторизация, подбор рецептов
├── server/              # серверные middleware
├── public/images/recipes/  # фото рецептов каталога
├── docs/                # проектная документация
│   ├── ТЗ.md            # техническое задание
│   ├── plan.md          # понедельный план работ со статусами
│   ├── db-schema.md     # схема базы данных
│   ├── uml/             # UML: диаграмма компонентов, диаграммы последовательностей
│   └── attachments/     # исходные учебные материалы
└── scripts/             # служебные скрипты (миграции, окружение, preview)
```
