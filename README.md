# Gastronomix 🍅

Веб-приложение для учёта продуктов и работы с рецептами: «цифровой холодильник»,
каталог из **40 рецептов** с КБЖУ и пошаговыми инструкциями, собственные рецепты,
предпочтения, недельное меню и список покупок.

## Возможности

- **Регистрация и вход** (email + пароль, better-auth); данные каждого
  пользователя изолированы.
- **Предпочтения** — сразу после регистрации: аллергены, диеты и стоп-лист
  продуктов (жёсткие фильтры), цель по КБЖУ, время, техника, любимые кухни
  и порции (ранжирование выдачи). Всё редактируется в профиле.
- **Холодильник** — продукты с количеством и сроком годности: ручной ввод,
  пресет «Базовый набор» и вставка списка из чека; индикатор свежести.
- **Каталог рецептов** — 100 блюд с фото, кухней, граммовками ингредиентов
  и пошаговым приготовлением.
- **Поиск и фильтры** — по названию/ингредиентам, калориям и времени; всё
  выполняется на сервере.
- **Избранное** — отметьте блюдо сердечком и смотрите только избранные рецепты.
- **Страница рецепта** `/recipes/:id` — полная карточка и кнопка
  «Я приготовил это», которая списывает ингредиенты из холодильника.
- **Планировщик меню** `/menu` — неделя × завтрак/обед/ужин/перекус,
  КБЖУ считается по плану, есть печать в PDF.
- **Список покупок** `/shopping` — собирается из меню минус холодильник,
  группируется по отделам, копируется в буфер и печатается.
- **Светофор свежести** — прогресс-бар жизни каждого продукта и виджет
  «Спаси меня сегодня» с кнопкой «Приготовить из этого».
- **Режим шеф-повара** — полноэкранная готовка по шагам с галочками
  и таймерами.
- **Пересчёт порций** — ползунок 1–8, граммовки пересчитываются,
  недостающее подсвечено.
- **Умные замены** — «Нет сметаны? Замените на греческий йогурт (есть дома)».
- **Ноль отходов** — в профиле: индекс, спасённые кг и ₽, график КБЖУ
  за неделю, топ покупок и выбрасываний (Recharts).
- **Конструктор** `/builder` — соберите боул/вок/салат без рецепта
  и спишите продукты из холодильника.
- **Импорт по ссылке** — вставьте URL рецепта, и форма заполнится сама.
- **Профиль** `/profile` — данные аккаунта, изменение имени, статистика.
- **Подбор по продуктам** — рецепты ранжируются по совпадению ингредиентов
  с содержимым холодильника, с подписью «сколько продуктов дома».
- **Шеф-ИИ** — чат на кухне, умное чтение ссылок и генерация новых рецептов
  (требуется ключ `DEEPSEEK_API_KEY`).
- **Свой рецепт** — создание, редактирование и удаление:
  - ингредиенты **с количеством** («курица — 400 г»), до 30 позиций;
  - **фото** блюда: JPEG/PNG/WebP, автоматически сжимается до 1000 px в браузере;
  - число порций и **КБЖУ** (калории, белки, жиры, углеводы);
  - способ приготовления.

## Технологии

- React 19 + TypeScript + Tailwind CSS 4
- TanStack Start (SSR + server functions) и TanStack Router
- better-auth — регистрация, вход, сессии
- PostgreSQL (Neon) или встроенная PGLite для локальной разработки —
  схема задаётся миграциями в `migrations/`
- zod — серверная валидация всех входных данных

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:8080`.

База данных:
- по умолчанию используется локальная **PGLite**: данные хранятся в
  `.data/pglite`, миграции применяются автоматически при старте;
- чтобы подключиться к **Neon/PostgreSQL**, задайте переменную окружения
  `DATABASE_URL` и выполните `npm run db:migrate`.

Шеф-ИИ (LLM):
- создайте облако в Yandex Cloud (для новых аккаунтов есть бесплатный
  стартовый грант), включите сервис **AI Studio** и получите API-ключ,
  скопируйте ID каталога;
- запишите обе строки в файл `.env` проекта:
  `YC_API_KEY=ваш-ключ` и `YC_FOLDER_ID=id-каталога`;
- включаются три функции: чтение ссылок без разметки, чат «Спросить шефа»
  и генерация рецептов для каталога (раздел «ИИ-каталог»);
- без ключа приложение работает как раньше, ИИ-функции просто сообщают,
  что нужно настроить ключ.

Проверки качества:

```bash
npm run typecheck   # tsc --noEmit
npm test            # 55 тестов (node:test)
npm run lint        # eslint
npm run build       # production-сборка
```

## Структура репозитория

```
├── migrations/          # SQL-миграции: auth, продукты/рецепты, каталог, фото, избранное, предпочтения, меню
├── src/
│   ├── routes/          # страницы: лендинг, вход, регистрация, «Кухня», рецепт, предпочтения, меню, покупки, профиль
│   ├── components/      # UI-компоненты (навигация и др.)
│   └── lib/             # API (server functions), БД, авторизация, подбор рецептов
├── server/              # серверные middleware
├── public/images/recipes/  # фото рецептов каталога
├── docs/                # проектная документация
│   ├── ТЗ.md            # техническое задание
│   ├── plan.md          # понедельный план работ со статусами
│   ├── db-schema.md     # схема базы данных
│   ├── uml/             # UML: диаграмма компонентов, диаграммы последовательностей
│   └── attachments/     # исходные учебные материалы
└── scripts/             # служебные скрипты (миграции, окружение, preview)
```
